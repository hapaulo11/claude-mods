# Avancement

Mod Claude Code qui affiche une barre d'avancement au-dessus de la zone de saisie : nombre d'étapes faites sur le total, et l'étape en cours. Quand tout est fini, la barre passe au vert avec un bouton « Effacer ». Le mod compacte aussi la conversation tout seul quand elle dépasse environ 400 000 tokens, en gardant les décisions, les fichiers modifiés et ce qui reste à faire.

## Installation

```
/plugin install avancement --marketplace hapaulo11/claude-mods
```

Répondre `y` pour ajouter la marketplace, puis choisir la portée « user » pour l'avoir dans toutes les sessions.
